Фундаментальные абстракции

    SoC (System on Chip) — Система на кристалле. Интегральная схема, объединяющая процессор (мозг) и ПЛИС (мускулы) в одном физическом корпусе.

    PL (Programmable Logic) — Программируемая логика. Область кристалла, состоящая из неконфигурированных логических вентилей (эквивалент классической ПЛИС). Программируется с помощью языков описания аппаратуры (HDL).

    PS (Processing System) — Процессорная система. Жестко заданная аппаратная часть чипа, включающая ядра ARM (Cortex-A9), кэш-память и контроллеры стандартной периферии (UART, USB, Ethernet).

    RTL (Register-Transfer Level) — Уровень регистровых передач. Способ описания цифровых схем (например, на языке Verilog), где логика описывается как потоки данных между регистрами.

Инструментарий и артефакты

    Vivado — Основная среда разработки (IDE) от Xilinx/AMD для синтеза, трассировки и генерации прошивок для ПЛИС.

    Vitis (бывший Xilinx SDK) — Среда разработки для написания программного обеспечения (на C/C++), которое будет выполняться на ядре ARM внутри PS.

    Bitstream (.bit) — Файл битового потока. Скомпилированная бинарная прошивка, содержащая физическую конфигурацию всех переключателей и трасс для матрицы PL.

    XDC (Xilinx Design Constraints) — Файл ограничений. Содержит привязку логических портов к физическим пинам (ножкам) чипа, а также временные ограничения (тайминги).

Архитектура и интерфейсы

    IP-Core (Intellectual Property Core) — Готовый аппаратный блок (модуль). Может быть жестким (Hard IP, например контроллер памяти) или мягким (Soft IP, синтезируемым из Verilog-кода).

    Block Design (BD) — Графический интерфейс в Vivado, позволяющий собирать сложные системы из IP-ядер путем соединения их шинами, подобно конструктору.

    MIO (Multiplexed I/O) — Физические выводы (пины) микросхемы, жестко подключенные напрямую к процессорной системе (PS).

    EMIO (Extended MIO) — Механизм проброса сигналов от периферии процессора (PS) наружу через матрицу программируемой логики (PL), если стандартных пинов MIO не хватило.

    AXI (Advanced eXtensible Interface) — Стандарт высокоскоростной внутрикристальной шины. Используется для обмена данными между процессором (PS) и логикой (PL).

Загрузка и инициализация

    FSBL (First Stage Boot Loader) — Загрузчик первого уровня. Небольшая программа на С, которая запускается процессором сразу после подачи питания. Ее задача — инициализировать оперативную память (DDR), настроить базовые частоты и загрузить основную прошивку в PL и ОС в PS.

    JTAG — Стандартизированный аппаратный интерфейс для прямой отладки и загрузки битстрима/кода прямо в память чипа в обход SD-карт и флеш-памяти.
